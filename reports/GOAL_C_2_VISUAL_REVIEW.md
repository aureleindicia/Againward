# Goal C.2 — Visual review

PDFs rendus puis inspectés en images à 120 dpi : C-A, C-B, C-D, C-E, C-I et
l'E2E multi-décision.

| Vérification | Résultat |
|---|---|
| Directive principale visible et cohérente | Oui |
| Décision négative pouvant sembler recommandée | Non |
| Bloc « après action » sur C-D / C-I | Non |
| Vérification préalable sur C-B | Oui |
| Activité binaire visuellement non ambiguë | Oui — bandes de fond, pas de ligne interpolée |
| Valeurs économiques repérables | Oui |
| Clipping / chevauchement observé | Non |
| Page artificielle ajoutée | Non |

Le rapport no-finding C-E tient volontairement sur une seule page : il contient
la conclusion, les vérifications, les limites et les sources, sans créer une
page de remplissage. Le rapport multi-décision répartit les quatre décisions sur
des pages successives; les suites de blocs se poursuivent sans chevauchement.

Le graphique C-A représente la consommation par une courbe bleue et les
périodes actives/inactives par bandes orange pâle/grises. Le PDF affiche son
axe temporel, son unité énergétique et sa légende dans le bloc graphique.
