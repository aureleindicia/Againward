# Goal C.1 — Agenticity audit

1. **If Codex were removed, could deterministic code produce substantially the
   same investigation and diagnosis? — NO.** Goal C has no diagnostic logic;
   it consumes Goal A/B states. The selection of client-relevant subjects,
   narrative, explanations and chart requests remains Codex work.
2. **Does Python measure/validate rather than decide? — YES.** It resolves
   references, reconstructs deterministic values, validates structural claim
   fidelity, generates a chart from a chosen real dataset and renders PDF.
3. **Can Codex explain a cause not encoded in a report template? — YES.** The
   claim contract binds the explanation to evidence but does not prescribe its
   causal wording.
4. **Can Codex choose a presentation and investigation outcome not foreseen by
   a fixed workflow? — YES.** It selects cards, relevant existing decisions,
   claims, useful charts and client questions; the contract only prohibits
   unsupported strengthening.
5. **Do the new tools expand Codex's action space? — YES.** Multi-decision
   persistence, negative cards and sourced claims allow more faithful delivery
   without choosing the underlying actions or decisions.
