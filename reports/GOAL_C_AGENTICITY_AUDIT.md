# Goal C — audit d'agenticité

Codex reste responsable de sélectionner les sujets, écrire le contexte,
formuler `why_this_matters`, choisir les graphiques et déterminer le niveau de
détail utile au client. Le contrat exige ce narratif; il ne le génère pas par
règles.

Python résout les références, vérifie les décisions/nombres/contraintes,
génère le graphique explicitement demandé et rend le PDF. Il ne choisit aucune
action, hypothèse, priorité ou explication contextualisée.

Si Codex était retiré, le code pourrait-il produire sensiblement le même récit
client contextualisé ? **NON.** Il produirait au mieux un rendu de valeurs sans
la sélection ni l'explication métier.
