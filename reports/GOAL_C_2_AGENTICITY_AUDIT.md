# Goal C.2 — Agenticity audit

- Codex choisit toujours les décisions Goal B à expliquer, les priorités, les
  hypothèses, les textes `why_this_matters`, les explications contextuelles,
  les graphiques et les demandes utiles.
- Python ne choisit aucune action, aucun diagnostic, aucune décision
  `ACT_NOW`/`INVESTIGATE_FIRST` et n'interprète pas le sens libre des documents.
- Python vérifie les liens, les nombres, les unités, la confidentialité et le
  rendu; la directive est une traduction déterministe de la décision déjà prise
  par Codex/Goal B.

Si Codex était retiré, le code ne pourrait pas produire sensiblement la même
investigation, les mêmes actions ni les mêmes explications : **NON**.

Goal C.2 automatise les opérations nécessaires à une communication fidèle; il
n'automatise pas le raisonnement ni la décision énergétique.
