# Goal C — revue adversariale

| Risque | Protection vérifiée |
|---|---|
| HIGH présenté comme valeur attendue | Les fourchettes rendent LOW–HIGH; seul un montant identique peut être exact. |
| Décision Goal B renforcée | Carte refusée si enum ou action sélectionnée diffère. |
| Économie/CAPEX modifié | Claim refusé s'il diffère du calcul déterministe source. |
| Contrainte dure cachée | Carte refusée si une contrainte matérielle affectant l'action est absente. |
| No-finding converti en recommandation | Refusé sans no-finding canonique/DO_NOTHING; aucune carte possible. |
| Alternatives additionnées | Groupes explicitement non additifs; total seulement via agrégation Goal B. |
| Jargon ou trace interne exposée | Le PDF est contrôlé contre IDs ART/FIND et chemins locaux. |
| Graphique décoratif | Un graphique exige une demande Codex, une source réelle et une question client. |
| Question inutile répétée | Les demandes avec GBE résolue sont retirées du dialogue client. |
| Économie théorique absurde promue | Goal C ne promeut que les actions sélectionnées par Goal B. |
| Confusion observé/inféré/estimé | Le modèle distingue observation, hypothèses et impact `POTENTIAL`. |

Limite : Python ne peut pas prouver la qualité rhétorique de chaque phrase
Codex. Il impose donc des références, interdit les nombres libres et rend les
faits structurés non modifiables; une revue humaine de livraison reste utile.
