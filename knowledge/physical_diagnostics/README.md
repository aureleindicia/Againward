# Knowledge layer de diagnostic physique

Ces fichiers JSON sont des références locales, génériques et auditables pour Codex.
Ils décrivent variables, chaîne énergétique, mécanismes possibles, prédictions,
grandeurs discriminantes, tests et risques. Ils ne sont ni exhaustifs ni exécutés comme
des règles. Le chargeur valide seulement leur structure.

Une cause absente reste autorisée. Un test absent reste autorisé. Aucun fichier ne porte
de probabilité de cause, de seuil de décision ou de correspondance automatique
observation-cause.

Familles :

- `refrigeration` ;
- `thermal_ovens` ;
- `compressed_air` ;
- `motors_pumps_fans` ;
- `laundry_hot_water_steam` ;
- `hvac`.
