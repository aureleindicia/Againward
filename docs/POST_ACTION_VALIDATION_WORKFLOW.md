# Validation après action

Chaque carte d'action reprend le plan Goal B : métrique, direction attendue,
fenêtre de comparaison, facteurs de confusion et preuve minimale. Le rapport
prépare donc une comparaison avant/après sans construire de monitoring continu.

Une économie reste potentielle ou attendue jusqu'à ce qu'une observation
post-intervention suffisante soit enregistrée dans un futur workflow de
validation. Goal C ne transforme jamais une estimation calculée en résultat
vérifié.
