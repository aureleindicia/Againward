# Espace d'exploration

Ce repertoire accueille les scripts et resultats ad hoc crees pendant une investigation.
Une experience ne rejoint `energy_mvp/` qu'apres generalisation, tests et documentation.

Ne jamais y melanger les donnees de plusieurs clients. Les entrees, donnees traitees et
sorties de workspaces clients doivent rester hors Git.

L'investigation synthetique se relance depuis la racine avec :

```sh
python -m workspace.demo_investigation
```
