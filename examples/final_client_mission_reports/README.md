# Rapports synthétiques de restitution

Quatre compositions éditoriales conçues par Codex : écart énergétique, fausse piste,
priorités multiples, abstention utile. Les contrats Goal A/B des fixtures existantes
fournissent les résultats ; ces documents ne valident pas un détecteur ni la valeur
commerciale du projet. Aucune approbation humaine de livraison réelle n’est fournie.

Reproduction depuis la racine, dans un nouveau dossier :

```sh
PYTHONPATH=. python workspace/generate_final_mission_reports.py scratch/report_examples_new
```

Les plans de composition sont inclus ; les modèles complets et leurs sources sont
reconstruits par ce générateur. Les horodatages de création des fixtures peuvent
modifier les hashes sémantiques internes. Le PDF reste lié aux résultats de chaque
exécution. `MANIFEST.json` décrit les octets effectivement inspectés ici.

Les revues visuelles attestent uniquement ces PDF synthétiques. Une mission réelle
exige sa propre composition, son inspection et son approbation humaine courante.
